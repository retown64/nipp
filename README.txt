日報アプリ（PWA）
================
このアプリはクラウド・ログイン・外部連携なしで動作します。
日報データは利用端末のブラウザ内に保存されます。

iPhone / iPad:
1. アプリをHTTPSで公開したURLをSafariで開く
2. 共有 →「ホーム画面に追加」
3. ホーム画面の「日報」アイコンから起動

Android:
1. Chromeで公開URLを開く
2. 「ホーム画面に追加」または「アプリをインストール」
3. ホーム画面から起動

重要:
iOS/Androidの本当のアプリとしてインストールするには、index.html等をHTTPSで公開する必要があります。
ZIPをファイルアプリから直接開くだけでは、PWAインストール機能は動作しません。
